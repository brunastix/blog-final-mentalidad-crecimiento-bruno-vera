# De datos desordenados a información confiable: mi aprendizaje con Excel

 Contexto

Durante mi formación en Data Analytics comencé a trabajar con bases de datos en Excel para realizar análisis y construir indicadores. Al principio pensaba que la parte más importante de un proyecto era crear gráficos y presentar visualmente los resultados.

Sin embargo, al trabajar con una base de datos comprendí que primero era necesario revisar, limpiar y organizar correctamente la información.

## Problema

El principal desafío fue detectar que los datos no estaban completamente preparados para ser analizados. Algunas columnas contenían formatos diferentes, ciertos valores estaban escritos de distintas maneras y existían registros que podían generar resultados incorrectos.

En un primer momento intenté avanzar directamente con tablas dinámicas y gráficos, pero los resultados no eran consistentes. Esto me permitió reconocer que el problema no estaba en las visualizaciones, sino en la calidad de los datos utilizados.

## Acciones

Para resolver el problema revisé las columnas individualmente, comprobé los tipos de datos y busqué valores duplicados, espacios innecesarios y diferentes formas de representar una misma categoría.

Organicé el proceso en las siguientes etapas:

1. Comprensión de la base de datos.
2. Revisión de valores y formatos.
3. Limpieza y estandarización.
4. Validación de los resultados.
5. Preparación de la información para el análisis.

Como parte de un post-mortem constructivo, reconocí que había comenzado por la etapa visual sin comprobar previamente la calidad de los datos. A partir de este análisis decidí incorporar una instancia de validación antes de construir cualquier indicador o dashboard.

## Aprendizajes

Esta experiencia me permitió comprender que la limpieza de datos no es una tarea secundaria, sino una parte fundamental del análisis.

También aprendí que un gráfico visualmente correcto puede representar información equivocada cuando los datos de origen contienen errores o inconsistencias.

En futuros proyectos voy a priorizar la comprensión, limpieza y validación de los datos antes de comenzar con el diseño del dashboard.

## Evidencia de control de versiones

Esta entrada fue desarrollada utilizando GitHub. Durante su elaboración se realizaron diferentes commits para documentar la creación inicial, las correcciones y las mejoras aplicadas al contenido.

## Feedback radicalmente sincero

Aplicar feedback radicalmente sincero implicó reconocer que mi primera forma de encarar el ejercicio no era la más eficiente. Estaba priorizando la presentación visual antes de verificar si la información era confiable.

En lugar de interpretar este error como un fracaso, lo utilicé para revisar mi proceso y establecer una metodología más ordenada. Esta reflexión me permitió comprender que recibir observaciones, cuestionar decisiones propias y corregir el trabajo son partes necesarias del aprendizaje técnico.
